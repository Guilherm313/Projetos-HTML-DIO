    • Clients

    Voltar

    Client é o dispositivo, utilizado por uma pessoa ou usuário, que está consumindo aquela informação através da internet, e indo para um server onde se encontram os sites. As informações do site estão todas dentro do server, o que ele faz é apenas interpretar a interação do usuário e devolver para a tela do dispositivo o resultado dessa interação.

    Navegadores

    Voltar

    os navegadores são programas que são instalados no dispositivo, que servem para interpretar arquivos vindos da web (HTML, JavaScript, CSS, imagens…), também chamados de browsers, todos os navegadores seguem o padrão W3C, mas sempre com uma diferença ou outra de interpretação.

    Aplicações Web

    Voltar

    como dito antes, aplicações web são soluções criadas que possuem a internet como meio de comunicação entre Client x Server não sendo necessário a sua instalação. uma aplicação web é um arquivo aberto direto no navegador, diferente de aplicativos instalados no computador.

    Servers

    Voltar

    servers são máquinas mais robustas, pois exigem mais processamento, pra aguentar várias informações sendo enviadas e recebidas simultaneamente. Os servidores não precisam necessariamente de internet para mandar e enviar dados, eles podem ser um servidor local, chamado de Local Area Network (LAN). Como por exemplo, um computador que armazena arquivos de outros computadores dentro da sua casa. Isso também é um servidor.

    existem diversos tipos de servidores, entre ele estão:

    1. Servidores de arquivos;
    2. Servidores de segurança (Firewall);
    3. Servidores de Streaming;
    4. Servidores de E-mail;
    5. Servidores de Web;

    Hardwares e Softwares

    Voltar

    todo servidor é baseado em duas partes, a lógica (software), e a parte física (hardware).

    Software

    1. Sistemas operacionais;
    2. Monitoramento;
    3. Servidores Web.

    Hardware

    1. Armazenamento (disco rígido, SSDs);
    2. Memória;
    3. Processadores.

    toda informação enviada por um client é chamada de requisição HTTP, e quando chega essa requisição, o sistema operacional recebe ela e manda pro servidor web processar e devolver a resposta (HTML, CSS, Javascript, imagens, etc).

    Linguagens de programação

    Voltar

    Linguagem de programação é uma linguagem escrita e formal que especifica um conjunto de instruções e regras usadas para gerar programas (software).

    Linguagem Server-side

    1. PHP;
    2. Java;
    3. JavaScript;
    4. C#;

    Linguagem Client-side

    linguagens Client-side são linguagens que são executadas apenas no lado do cliente. O javascript também funciona do lado do cliente, por conta de uma aplicação criada pelo google chamada V8.

    HTML

    Voltar

    O HTML não é uma linguagem de programação, ele é uma linguagem de marcação de hipertexto. Hipertextos são textos delimitados por nome que o navegador consegue interpretar, e cada nome destes delimitadores, tem uma função e comportamento específico.

    Exemplo usando arquivo CSV:

    Id;Nome;Idade;Email

    1;Maria Lucia;43;maria@dio.me

    2;Jorge Almeida;23;jorge@dio.me

    o ponto e vírgula ( ; ) está sendo a marcação do texto.

    Estrutura básica de HTML

    é assim que se escreve uma estrutura básica de HTML:

    
                    <html>
                        <head>
                            <title>Mudei o título<title>
                        <head>
                        <body>

                        <body>
                    <html>

    Tags

    Voltar

    as Tags são funções para modificar o texto. Algumas delas são:

    1. <i>Meu primeiro HTML </i> - Essa tag faz com que o texto fique em itálico;

    2. <strong> Meu primeiro HTML </strong> - essa tag faz com que o texto fique em negrito;

    3. <input type=”text” /> - essa tag faz com que o úsuario possa escrever em um campo do site. Esses tipos de tags abrem e fecham dentro do mesmo campo;

    Atributo de tags

    Atributos são propriedades que uma tag pode ter. E cada tag pode ter um atributo global, que serve pra todas, e um atributo específico para aquela tag. Como por exemplo o atributo id na tag strong (<strong id=”titulo”> </strong>)

    1. O atributo “id” serve para buscar um identificador na tag escolhida, para depois ser mais fácil modifica-la através de JavaScript.

    2. Outro atributo muito utilizado é o “style”, ele deixa você direto do HTML, fazer modificações de CSS, como mudar a cor e etc.

    3. E por ultimo dos atributos mais utilizados, é o “class”. Exemplo: <strong class=”titulo-principal”> </strong>. Isso faz com que todo código com o id “titulo-principal” seja modificado de uma forma que você pré determinou.

    E agora alguns atributos específicos de determinadas tags:

    1. O input possui alguns atributos específicos dele, como o type, que deixa você escolher o tipo de texto que vais ser escrito, ou até mesmo a cor que vai ser escolhida. Exemplo: <input type=”number” />, Esse tipo do atributo type deixa o usuário digitar apenas números num campo específico do site.

    2. E outro exemplo é o “img”, que tem como atributo específico dela o “src”. O que o img faz é pegar uma imagem do navegador ou da memória do computador do desenvolvedor.

    Textos

    Voltar

    A maioria dos sites são compostos por texto, e existem tags específicas para textos no HTML.

    1. uma tag utilizada para fazer títulos e subtítulos, é o “h1”, que pode ir até o “h6”. Cada “h” representa um subtítulo.;

    2. para fazer parágrafos de textos é utilizada a tag “p”;

    3. para fazer uma citação de algum cientista ou algo do tipo, é utilizada a tag “blockquote”.

    Listas ordenadas e não ordenadas

    Voltar

    as listas ordenadas são listas que, como o próprio nome já diz, seguem uma ordem sequencial. Ela é declarada da seguinte forma:

     
    <html>
        <head>

        </head>
        <body>
            <ol>
                <li>;Item 1 </li>
                <li>;Item 2 </li>
                <li>;Item 3 </li>
            </ol>
        </body>
    </html>

    Onde “ol” declara a lista ordenada, e “il” lista os itens.

    E as listas não ordenadas, são listas com marcadores, ao invés de numerar sequencialmente. Exemplo de como ela é declarada:

     
    <html>
        <head>

        </head>
        <body>
            <ull>
                <li>;Item 1 </li>
                <li>;Item 2 </li>
                <li>;Item 3 </li>
            </ul>
        </body>
    </html>

    é quase a mesma coisa da lista ordenada, só que ao invés de “ol”, se escreve “ul”.

    Links

    Voltar

    Para colocar links no site deve-se utilizar a tag “<a>”. Exemplo:

     
    <html>
        <head>

        </head>
        <body>
            <ull>
                <li>
                    <a href="http://dio.me"> </a>
                </li>
            </ul>
        </body>
    </html>
    1. o atributo “href” é a referência, ou seja, o link.

    2. Outro atributo utilizado é o “target”, deixa o desenvolvedor decidir se o link vai ser aberto direto na mesma aba, ou se será aberto em uma aba diferente.

    3. Outro atributo é o “title”, que deixa um subtítulo no link.
